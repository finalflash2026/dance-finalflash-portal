# 大規模アップデート 計画メモ(feat/major-update)

SPEC.md に反映する前の合意事項・懸念・バックログ。実装に入る項目は先に SPEC.md を更新してから着手する(§2.2)。

## 決定事項

### 1. 大規模イベント
- 登録・編集できるのは **3役(admin)と折衝(coordinator)だけ**。
- 縦イベには「OB/OGにも見せる」印を付けられる。それ以外は現役のみに表示。
- カレンダー(統合後のメインカレンダー)と購読 ics に出す。

### 2. 期限(集金・フォーム)
- 対象は基本 **現役全員**。
- **済/未済は管理しない**。期限の表示とリマインドだけ。
- 2ジャン(サブジャンル)登録フォームの締切もこの仕組みに載せる。
- 「大事な締切」(集金など)と通常の締切を区別する。

### 3. リマインド(毎朝1回の Cron)
- **練習がある日の朝**:「今日は◯◯練があります」(締切とは無関係)。
- **締切の当日朝**。
- **大事な締切は1週間前の朝にも**。

### 4. カレンダーの統合
- マイ/全体の2つをやめ、**メインのカレンダー1つ**にする。
- 自分に関係するもの(自ジャンルの公式練・自分の申請・ナンバー・スタ練・イベント・締切)を主に、**空きコマと他ジャンルの練習は薄色**。
- カレンダー下に日別タイムテーブルを並べる今の配置は見づらい → 週の帯 + 選んだ日の予定リストを提案中。部屋×時間の表は切替で出す。

### 5. 鍵の開け閉め
- **1タップで通知まで飛ぶのをやめる**。確認画面 + 別の報告方法(スライドで報告・一言メモ・5秒間の取り消し)を提案中。

### 6. UI の抜本的な見直し
- カードの積み重ね、説明文の多さ、ボタンの形の不統一を解消する。Apple HIG 準拠。外部ライブラリ可(Konsta UI + Lucide を提案中)。
- 設定アイコンは歯車。
- テーマ切替を分かりやすく(自動/ライト/ダーク)。

### 7. ナンバー管理
- 機能は良い。主催者・メンバー双方に分かりやすくする。

### 8. 案内まわり
- 通知未設定の人に起動時ポップアップ。ブラウザで見ている人にはホーム画面追加を促す。**毎回ではなく数回に1回**。
- カレンダー購読の使い方を説明(iPhone はワンタップ登録 / Google はブラウザ必須・反映が遅れる)。
- **? ボタンでヒント**。初回は対象以外を暗くして吹き出しで案内するチュートリアル。? から見返せる。

### 9. 起動アニメーション
- ロゴから作った動的アニメーション。試作: `prototypes/splash/index.html` / `prototypes/splash/splash.mp4`。
- ~~背景透過のロゴ原本があれば差し替えたい~~ → 切り抜くと縁に溝が出たため、**閃光の中でポスター原画そのものへ切り替える方式**にした(ロゴと光線が元から一体)。

### 11. ホーム画面を短くする(2026-10-10 昼に決定)
下までスクロールしないと必要な情報に届かないのが一番使いにくい。ホームには**すぐ見たいものだけ**を置き、他は入口から別の画面へ移す。
- **今日**: 今日の自分の予定と近い締切を1つの欄にまとめる。
- **今日自主練できる部屋**: 今日の空き時間(空き申請できる時間帯)を部屋ごとに。押すと申請。
- **鍵のボード・部室の鍵・連絡**はホームから外し、1行の入口から別の画面へ。
- **お知らせ**はヘッダーのベル(未読の数)へ。
- **カレンダー**: 上に1週間の帯(横に滑らせて前後の週、押すと月表示に広がる)、下に選んだ日の予定。**ネイティブアプリのようになめらかに動かす。**
- **絞り込み**: 既定は自分の予定だけ。他ジャンルの練習・空きはジャンルごとに足せる。「全部」「自分の予定だけ」で一括切り替え。

### 10. 追加機能(採用)
- **3役からの全体告知**(通知付き)。
- **今空いている部屋**の一覧(そこから申請)。

## 懸念事項(サークル内で意見を聞いて決める)

- **「閉めました」の報告・通知は必要か。** 開いたかどうかだけ伝われば十分なら、閉めた報告を通知なしにして通知量を半分にできる。代表者だけで決めず、メンバーの意見を聞いて決める。

- **iOS アプリを TestFlight / App Store で配るか。** Apple Developer Program が年額 (約1.5万円) 掛かる。誰の名義で、サークルの費用から出すかを決める。配るならネイティブの通知 (APNs) も同じアカウントで使える (SPEC §2.3)。

## 質問(朝に確認したいこと)

1. **告知を「OB/OGにも送る」にしたとき、OB にはアプリ内のお知らせだけが届く。** OB には通知の設定欄が無い(§6.6)ため。OB にもプッシュ通知を届けたいなら、OB の設定画面に通知欄を出す必要がある。どうする?
2. **締切の対象は「現役全員」固定にした。** 「23期だけ」「BREAKだけ」のように絞りたい締切はある?(あれば対象期・ジャンルの指定を足す)
3. **テーマの既定。** 何も選んでいない人は今まで通りダーク。新しい「自動」(端末に合わせる)を既定にする?
4. **リマインドの時刻のずれ。** Vercel の無料プランの Cron は「その1時間のどこか」で動くので、7:00〜7:59 の間に届く。気になるなら有料プランか、6時台に早める。
5. **イベントと締切は、絞り込み(BREAK だけ等)をしても常に表示**にした。合宿の日に BREAK を選んだら合宿が消える、のを避けるため。これでよい?
6. **ナンバー管理**は要件だけ SPEC に書き、画面は変えていない。手順ガイド・毎週の一括作成・出欠人数・資料リンク(提案中)や「主催/メンバーで一覧を分ける・次の日程を出す」のうち、どれを進める?
7. **UI ライブラリ(Konsta UI)は入れていない。** 決定が「提案中」だったので、自前の部品で iOS 風に寄せた。この方向でよければ残りの画面(折衝・管理・ナンバー詳細)も同じ部品に揃える。
8. 起動アニメーションは**ログイン画面でも**流れる(アプリを開いた最初の画面で1回)。ログイン後だけにする?
